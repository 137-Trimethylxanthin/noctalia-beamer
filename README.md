# Beamer

![Beamer in the Noctalia launcher](beamer/thumbnail.webp)

Hyprland has no "Win+P" menu. Beamer puts **Extend**, **Duplicate**, **External
only** and **Laptop only** in the [Noctalia](https://noctalia.dev) launcher, on a
control-center tile, and behind one IPC call you can bind to your laptop's
display key.

This repository is a **Noctalia plugin source**. Add it once and the plugin shows
up in the plugin store like any other, updates included.

## Install

```sh
noctalia msg plugins source add beamer git https://github.com/137-Trimethylxanthin/noctalia-beamer
noctalia msg plugins enable 137-trimethylxanthin/beamer
```

`source add` clones the repo into Noctalia's plugin cache; `enable` exports the
plugin and starts it. Both are also available in **Settings → Plugins**, where
`https://github.com/137-Trimethylxanthin/noctalia-beamer` goes in under *Sources
→ Add*.

To pick up a new version later:

```sh
noctalia msg plugins update beamer
```

Requires Hyprland with `hyprctl` on `PATH`. Full documentation — layouts, the
`/beam` launcher prefix, the `cycle` shortcut, IPC events and the caveats worth
knowing before a talk — is in **[`beamer/README.md`](beamer/README.md)**.

## Repository layout

```
beamer/           the plugin itself; this is what Noctalia exports
  plugin.toml     manifest: id, entries, metadata
  *.luau          entry scripts
  lib/            shared modules
  translations/   label_key / description_key strings
  README.md       the plugin's page in the store
  thumbnail.webp  its card image
catalog.toml      source index; regenerated by CI on every push
```

`catalog.toml` is what makes the git route work: Noctalia reads it to render and
compat-check the source before cloning anything else. It is generated from
`beamer/plugin.toml` by `.github/workflows/update-catalog.py` and committed, so
bumping `version` in the manifest is all a release takes. To regenerate it by
hand:

```sh
python3 .github/workflows/update-catalog.py
```

## Developing

Point Noctalia at your checkout instead of at GitHub — a `path` source is scanned
directly, with no catalog involved, and `.luau` edits hot-reload:

```sh
noctalia msg plugins source add dev path ~/Documents/code/noctalia-beamer
noctalia plugins lint beamer
```
